# Changelog

All notable changes to Missio are recorded here.

## 0.8.0 - 2026-06-15

### Added

- Schema-native GraphQL request creation, editing, execution, fixtures, and Copilot support.
- WebSocket request creation, execution, lifecycle handling, fixtures, and Copilot support.
- gRPC unary and streaming request support backed by protobuf definitions and local demo services.
- Protocol-neutral runtime scripts, tests, assertions, actions, diagnostics, and response output.
- API key, OAuth2, CLI, proxy, redirect, and mutual-TLS transport support with secret redaction.
- Protocol-aware import, export, snippet, tree, CodeLens, and request-creation diagnostics.
- PDF response preview using the official Mozilla PDF.js distribution copied during build and packaging.

### Changed

- Updated the extension version to 0.8.0.
- Expanded OpenCollection schema round-trip validation and editor preservation across supported protocols.
